# Stone & Temple Carving Website

A static website scaffold for a premium stone carving and temple restoration business.

## Files included

- `index.html` — landing page with brand messaging and portfolio preview
- `about.html` — company story, mission, founder profile, and differentiators
- `portfolio.html` — gallery of featured stone projects
- `services.html` — service offerings with detailed descriptions
- `materials.html` — stone type guidance and material expertise
- `achievements.html` — awards, certifications and testimonials
- `process.html` — step-by-step project workflow
- `contact.html` — inquiry form and contact details
- `faq.html` — frequently asked questions
- `styles.css` — site styles and responsive layout
- `script.js` — mobile menu toggle and header scroll behavior
- `robots.txt` — SEO and crawler settings
- `sitemap.xml` — page index for search engines
